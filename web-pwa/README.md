# Daily (web-pwa) — earlier prototype

This is the original installable-web-app prototype (clock, weather,
calculator, flashlight, timer, unit converter, notes). It's a free utility
bundle and was superseded by `mobile/` — a native iOS/Android app with an
AI-powered voice journal as the paid product, since a free multi-tool PWA
doesn't have a real path to a subscription users pay for.

Kept here in case any of it is useful later. To run it:

```bash
cd web-pwa
python3 -m http.server 8000
```
